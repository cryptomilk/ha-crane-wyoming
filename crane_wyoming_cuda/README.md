# Home Assistant App: Crane Wyoming (CUDA)

![Supports amd64 Architecture][amd64-shield]

Local text-to-speech (TTS) and speech-to-text (ASR) using the
[crane-wyoming](https://codeberg.org/cryptomilk/crane-wyoming) inference engine
via the Wyoming protocol, with NVIDIA CUDA GPU acceleration.

Requires a host with an NVIDIA GPU and the NVIDIA Container Toolkit configured.
If you don't have an NVIDIA GPU, use the [Crane Wyoming](../crane_wyoming) app
instead.
