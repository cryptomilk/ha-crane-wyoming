# Home Assistant App: Crane Wyoming

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]

Local text-to-speech (TTS) and speech-to-text (ASR) using the
[crane-wyoming](https://github.com/cryptomilk/crane-wyoming) inference engine
via the Wyoming protocol.
